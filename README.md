# Words Length Calculator

A simple web app that counts the number of words in a sentence typed by the user.

## Features
- Clean, responsive card-style UI
- Real-time word count calculation
- Handles empty input with a friendly message
- Splits words using spaces, commas, periods, and hyphens as separators

## Tech Stack
- HTML5
- CSS3
- JavaScript (Vanilla)

## How It Works
1. Type a sentence in the textarea
2. Click the "Calculate Words" button
3. The word count is displayed instantly
